A make.fun entry for **Loading Screen Gold**: one loading-screen tip in a single line, written for the two readers who actually stare at loading screens — the stressed developer and the AI coding agent working beside them. The program writes the tip to `/output/entry.txt`, guarded at runtime to the sealed 1–200 character, single-line gate, with a round-trip check that what lands on disk is byte-identical to the guarded line.

The tip: *"Tip: If the tests pass on the first try, one of you is lying. Check which one before you celebrate."*

## Run it

```sh
npx tsx main.ts
```
